# VeryBerryLab — Project Spec

## 1. Product Requirements

### 1.1 Для кого продукт
VeryBerryLab — это мобильное приложение для клиентов сервиса букетов и подарков (клубника в шоколаде, ягоды, дополнительные ингредиенты, доставка).

Основные пользователи:
- Частные клиенты, покупающие подарки
- Повторные клиенты (лояльность, бонусы)
- Администраторы бизнеса (через админку)

### 1.2 Какую проблему решает
- Удобный выбор и заказ букетов без общения в мессенджерах
- Прозрачная цена с учётом модификаций и доставки
- Централизованное управление каталогом, ценами и заказами
- Подготовка продукта к масштабированию и реальным пользователям

### 1.3 Основная функциональность (MVP)
**Для клиента (iOS):**
- Просмотр баннеров и категорий
- Просмотр товаров
- Детальная страница товара с модификаторами
- Авторизация по SMS
- Просмотр профиля
- (следующий этап) корзина, заказ, оплата, доставка

**Для администратора (Web):**
- Управление категориями и товарами
- Управление группами товаров
- Управление модификаторами (ягоды, добавки и т.д.)
- Назначение модификаторов группам товаров
- Управление заказами и статусами
- Управление зонами доставки и ценами

## 2. Engineering Requirements

### 2.1 Стек (фиксированный)

**Backend**
- Python 3.11+
- FastAPI
- SQLAlchemy 2.0
- Alembic
- PostgreSQL
- JWT (клиент)
- Cookie-based session (админка)
- Docker + docker-compose

**Admin Frontend**
- React
- TypeScript
- Vite
- Ant Design
- React Query
- Axios (withCredentials)

**iOS App**
- Swift
- SwiftUI
- async/await
- URLSession
- Keychain (позже)

**Infrastructure**
- Docker
- Nginx (в проде)
- VPS
- HTTPS

---

### 2.2 Архитектура (компоненты и связи)

[iOS App] ––––
—> [FastAPI Backend] —> [PostgreSQL]
[Admin Web] ——/

FastAPI:
	•	API для клиентов (/auth, /catalog, /orders)
	•	API для админки (/admin/*)
	•	Сервисы расчёта цены
	•	Логика модификаторов и групп товаров

---

### 2.3 База данных

Основные сущности:
- Users
- Products
- Categories
- ProductGroups (группы товаров)
- Modifiers
- ModifierOptions
- ProductGroup ↔ Modifiers (many-to-many)
- Orders
- OrderItems
- DeliveryZones
- PromoCodes
- Banners
- LoyaltySettings

База: **PostgreSQL**

---

### 2.4 Инфраструктура

**Разработка**
- Backend: localhost:8000
- PostgreSQL: Docker
- ngrok для мобильного тестирования

**Продакшн (план)**
- VPS (Hetzner / DigitalOcean / Selectel)
- Docker + docker-compose
- PostgreSQL в контейнере или managed
- Nginx + HTTPS
- Один публичный домен для API

---

## 3. Принципы развития

- Backend — источник истины
- Мобильное приложение максимально тонкое
- Все цены считаются на сервере
- Админка — главный инструмент управления бизнесом
- Архитектура готова к росту пользователей
